엑셀 수식이 필요할 때마다 검색해서 블로그 예제를 내 데이터에 맞게 고치느라 30분씩 쓰고 있다면, AI에게 바로 물어보는 편이 훨씬 빠릅니다. 단, **질문하는 방법**에 따라 한 번에 맞는 수식이 나오기도 하고, 열 번을 고쳐도 안 맞기도 합니다.

## AI가 엉뚱한 수식을 주는 이유

"매출 합계 구하는 수식 알려줘"라고 물으면 AI는 내 시트를 볼 수 없으니 `=SUM(A1:A10)` 같은 일반적인 예시를 줄 수밖에 없습니다. AI에게 필요한 정보는 딱 세 가지입니다.

1. **데이터가 어느 열에 어떻게 있는지**
2. **결과를 어디에 어떤 모양으로 원하는지**
3. **어떤 버전의 엑셀을 쓰는지** (XLOOKUP, FILTER 같은 함수는 구버전에 없습니다)

## 복붙용 엑셀 수식 프롬프트

```
엑셀(또는 구글 시트) 수식을 만들어줘.

- 데이터 구조: [예: A열 날짜, B열 담당자, C열 매출액, 2행부터 데이터]
- 원하는 결과: [예: 담당자별 이번 달 매출 합계를 F열에]
- 사용 프로그램: [엑셀 365 / 엑셀 2016 / 구글 시트]

수식과 함께:
1. 수식이 어떻게 작동하는지 한 줄씩 설명
2. 자주 발생하는 오류와 해결법
```

## 가장 정확한 방법: 데이터 몇 줄을 그대로 붙여넣기

열 구조를 말로 설명하기 어렵다면, 헤더와 데이터 3~5줄을 엑셀에서 복사해서 그대로 붙여넣으세요. 표 형태가 유지되어 AI가 구조를 정확히 파악합니다.

> 고객 이름, 전화번호 같은 개인정보는 `고객A`, `010-XXXX-XXXX`처럼 바꿔서 붙여넣으세요.

## 자주 쓰는 요청 예시

| 하고 싶은 것 | 이렇게 요청하세요 |
|---|---|
| 조건별 합계 | "B열이 '김철수'이고 A열이 10월인 행의 C열 합계" |
| 다른 시트에서 값 찾기 | "Sheet2의 A열 코드와 일치하는 행의 C열 단가를 가져와줘" |
| 중복 제거 목록 | "B열 담당자 이름을 중복 없이 F열에 나열해줘" |
| 조건부 표시 | "C열이 목표(D열)보다 작으면 E열에 '미달' 표시" |
| 날짜 계산 | "A열 계약일로부터 영업일 기준 14일 뒤 날짜" |

## 수식이 에러가 날 때

에러가 나면 고민하지 말고 같은 대화창에 이렇게 보내세요.

```
이 수식을 넣었더니 [#N/A / #VALUE! / #REF!] 에러가 나.
수식: [넣은 수식]
해당 셀의 실제 값 예시: [값]
원인과 고친 수식을 알려줘.
```

대부분 숫자가 텍스트로 저장되어 있거나, 찾는 값 앞뒤에 공백이 있거나, 범위가 어긋난 경우입니다. AI가 원인을 짚어주고 `TRIM`, `VALUE` 같은 보정 함수를 붙인 수식을 다시 줍니다.

## 요약

- 데이터 **위치·결과 위치·엑셀 버전** 세 가지를 꼭 알려준다.
- 가능하면 **헤더 + 데이터 몇 줄**을 그대로 붙여넣는다.
- 수식만 받지 말고 **설명과 흔한 오류**까지 함께 요청한다.
- 에러가 나면 **에러 코드와 실제 값**을 붙여 다시 묻는다.
